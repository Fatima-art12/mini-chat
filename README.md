# 💬 Mini Chat

A cute real-time chat app built with Node.js, Express and Socket.io.
Open it in two browser windows and chat instantly!

## ✨ Features

- Real-time messaging between multiple users
- Usernames shown with every message
- "Joined" and "left" notifications
- Live typing indicator
- Message timestamps
- Cute pink-purple UI design

## 🛠️ Tech Stack

- **Backend:** Node.js, Express, Socket.io
- **Frontend:** HTML, CSS, JavaScript

## 🚀 How to Run

1. Clone the repository

```bash
git clone https://github.com/Fatima-art12/mini-chat.git
cd mini-chat
```

2. Install dependencies

```bash
npm install
```

3. Start the server

```bash
node server.js
```

4. Open `http://localhost:3000` in two browser tabs and start chatting!

## 📚 What I Learned

- How real-time communication works using WebSockets (Socket.io)
- Handling events between client and server (`emit` and `on`)
- Broadcasting messages to multiple users
